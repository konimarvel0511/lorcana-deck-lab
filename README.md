# Lorcana Deck Lab

Disney Lorcana のデッキリストから、狙ったカードを引ける確率とインクの安定度を計算するWebアプリです。

## できること

- **デッキの読み込み**: 「4 カード名」形式のテキストを貼り付けて読み込む。表でコスト・インク可否・色を入力する
- **狙ったカードを引ける確率**: 初手7枚と、1〜8ターン目までに引けている確率。先攻/後攻、必要枚数、マリガンの有無を切り替えられる
- **インクの安定度**: 毎ターン欠かさずインクを置ける確率と、初手に含まれるインク可能カードの枚数分布
- **コスト分布**: コストごとの枚数（インク可能/不可の内訳つき）、平均コスト、色ごとの枚数

入力したデッキはブラウザに保存され、次に開いたときも残ります。

## 動かし方

ビルドは不要です。このフォルダで次を実行し、ブラウザで http://localhost:5173 を開きます。

```
npm start
```

テストは次で実行します（Node.js 20以上）。

```
npm test
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `styles.css` | 画面とデザイン |
| `src/main.js` | 画面の描画と操作 |
| `src/prob.js` | 確率計算（超幾何分布、マリガン、インク） |
| `src/deck.js` | デッキリストの読み取りと集計 |
| `src/cards.js` | カード情報の自動入力（試験的） |
| `tests/` | 計算とデッキ読み取りのテスト |

## 計算の前提

- 山札はよく切られている前提で、超幾何分布で計算します
- 初手は7枚。先攻は1ターン目にドローしません
- マリガンは「初手に必要枚数がなければ、対象以外をすべて山札の下に戻し、同じ枚数を引いてから山札を切る」場合の確率です
- インクの安定度は「インク可能なカードを引いたら必ずインクに置く」前提で、マリガンは含みません
- カードの効果による追加ドローは含みません

## カード情報の自動入力について

「コストとインクを自動入力」は [Lorcast](https://lorcast.com) の公開APIを使います。英語の正式名（`名前 - バージョン`）に完全一致したカードだけを入力します。実際のAPIに対する動作確認はまだできていないため、試験的な機能です。取得できない場合は表に直接入力してください。
